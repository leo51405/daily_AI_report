Partial Routing 依子任務難度分派模型，降低 Agent 工作流成本
arXiv cs.AI

Partial Routing 以執行軌跡調整任務內部的模型委派，讓簡單子任務交給較便宜的模型、困難部分再交由能力較強的模型處理。相較於整個 Agent 任務只選一種模型，這種細粒度路由可望兼顧成本與能力。

工程師解讀
值得知道
新在哪裡
Partial Routing 不是替整個任務選一個模型，而是由較強的主模型依子任務難度與過往品質、成本資料，決定是否委派部分工作給較便宜的模型，且不需訓練模型。

可用於包含簡單與困難步驟的 Agent 工作流，例如讓便宜模型處理重複或較容易的子任務，將較難部分留給主模型以控制成本。
