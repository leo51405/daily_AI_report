Google 推出 Gemini 4 Neon：百萬 token 脈絡，主打程式代理任務

Gemini 4 Neon 支援 100 萬 token 脈絡，在 AA Intelligence Index 得分 61，並登上 AA Coding Agent Index 第一名。API 價格為每百萬輸入 token 3 美元、輸出 token 15 美元；Google 將它定位為適合長時間、多步驟工作的模型。
