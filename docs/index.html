NVIDIA 開源連續擴散語言模型，最高解碼速度達自回歸模型 4.2 倍

NVIDIA 發布 Nemotron-Labs-Sigma，提供 14 個 3B、8B 參數的開放模型檢查點，以連續擴散方式在 16 維嵌入空間逐步去噪生成文字。透過少步數取樣器蒸餾，解碼速度最高可達自回歸解碼的 4.20 倍。

AWS 提出分散式 KV Cache 技術，推論成本最多降 40%
AWS Machine Learning

AWS 示範以 Amazon ElastiCache 建立分散式 KV Cache，減少自架 LLM 在多輪對話中重算相同上下文的成本。AWS 表示，此做法最多可降低 40% 推論成本，並將首個 token 延遲降低 80%。

工程師解讀
值得試玩
新在哪裡
AWS 的分散式 KV Cache 以 GPU 叢集旁的共享快取層，讓不同伺服器及後續工作階段重用 KV 狀態，減少長上下文請求重複執行 prefill。
能做什麼
適合評估自架 vLLM 或 SGLang 的長上下文服務，例如需要恢復法律案件對話、程式代理工作階段或文件問答的 GPU 推論叢集。
能否試用
原文介紹 Agent Toolkit for AWS 的 KV 快取技能，可搭配支援 Agent Skills 的 Kiro、Claude Code、OpenAI Codex 等工具協助評估與設定；原文未提供相關連結。
限制
需符合特定硬體與軟體條件，包括支援 EFA RDMA write 的 GPU 執行個體、LMCache、vLLM 或 SGLang，以及設定快取時使用 ElastiCache for Valkey 9.1 以上的指定節點；節省幅度取決於工作負載，最高 40% 成本與 80% 首 token 延遲改善為 AWS 所述結果。
