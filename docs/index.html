DeepMind 以 AI 代理形式化驗證 Signal 核心程式庫

DeepMind 以 AlphaProof Code 驗證 Signal 的 libsignal，將安全性證明延伸至編譯後的機器碼，涵蓋前向保密、身分驗證及入侵後安全性恢復。5 名研究人員與 AI 代理合作，4 週內產生約 650 萬行 Lean 證明程式碼，讓原本可能耗時數年的驗證工作大幅加速。

可作為高安全性軟體的驗證參考，例如確認加密通訊程式的編譯成品符合前向保密、身分驗證等安全規格。
